# Mahak Birthday V6 — Love Scrapbook

A completely different mobile-first design for Uday & Mahak.

Story: 28 January 2026 was the first time Uday saw/met Mahak and the same day they got engaged.
Birthday: 18 November.

Features: responsive phone/desktop design, 5 pages, photos, video, Uday portrait, separate MP3 per page,
old-page audio stops on navigation, new page attempts its own track, first-tap audio unlock, static hosting ready.

MP3 names: music/home.mp3, story.mp3, memories.mp3, engagement.mp3, letter.mp3

LOCAL TEST: python3 -m http.server 8000 then open http://localhost:8000

PHONE LINK: upload this folder to GitHub Pages or Netlify (or another static host) and share its HTTPS link.
Mahak only needs a phone browser; your PC does not need to stay on.
